# VGS Covers

Box art (front, back, spine, 3D box) for VideoGameShelf, generated by VGS Cover
Engine in the **VGS Covers manifest v2** format.

    vgs-source.json                 descriptor: licence default and one shard per platform
    manifest/<platform>.<hash>.json games -> releases -> assets -> renditions
    art/<platform>/<letter>/<game>/<type>.<region>.std.v1.<hash>.<jpg|png>
    index.json                      V1-style list for other tools

Every shard and image is listed with its SHA-256 (64 lower-case hex digits) and
image names contain the first 8 characters of their own hash, so files never
change in place. `.gitattributes` turns off line-ending conversion: changing a
single byte breaks the hashes.

Licensing: see `licence.artwork_default` in `vgs-source.json`. The images come
from LaunchBox Games Database community uploads; the artwork belongs to its
publishers. VideoGameShelf only serves images marked `permitted` from a remote
repository.
